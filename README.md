# Proxmox Cybersecurity Home Lab

A segmented virtualization environment built to develop practical
experience in network security, Linux administration, Windows and
Active Directory, vulnerability testing, security monitoring, and
incident response.

The lab runs on a Dell OptiPlex 7090 SFF using Proxmox VE. OPNsense
provides routing and firewall enforcement between the upstream network
and an isolated cybersecurity network.

All security testing is performed only against systems I own and have
explicitly designated as laboratory targets.
